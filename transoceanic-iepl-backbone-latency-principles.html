Windows 11 与 macOS 更新后网络异常：排查与回退

来源：扬帆云使用手记日期：2026-11-10分类：系统维护

一、更新后为什么会出问题

系统更新可能替换网卡驱动、改变网络栈或安全策略，原来的客户端与驱动因此出现兼容问题。

二、先做简单的处理

  • 重启电脑，让更新完整生效。
  • 关闭再开启无线网络或网线适配器。
  • 重新启动并更新代理客户端。

三、重置网络与更新驱动

Windows 可以使用网络重置功能，macOS 可以删除并重新添加网络服务。同时到官网更新网卡驱动。

四、回退更新

Windows 在更新后的一段时间内可以回退到上一版本；macOS 则可以通过备份恢复。回退前备份重要数据。

五、预防措施

更新前创建还原点或备份，关键设备推迟几天更新，先看看其他用户是否反馈问题。
